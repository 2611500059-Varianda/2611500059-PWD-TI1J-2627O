# pertemuan-08PERTEMUAN 08

Formulir Permohonan Peminjaman Fasilitas Kampus

1. Deskripsi

Mengembangkan aplikasi web Profil Mahasiswa dengan menambahkan fitur Permohonan Peminjaman Fasilitas Kampus.

2. Fitur

- Menu Beranda
- Menu Tentang
- Menu Kontak
- Menu Peminjaman Fasilitas
- Formulir peminjaman fasilitas kampus

3. Data Formulir

- Nama Penanggung Jawab
- Jenis Fasilitas
- Tanggal Peminjaman
- Durasi Peminjaman (jam)
- Keperluan Peminjaman

4. Pilihan Fasilitas

- Ruang Kelas
- Aula
- Laboratorium Komputer
- Proyektor

5. Pemrosesan Data

- Menggunakan metode POST.
- Validasi JavaScript dan PHP.
- Sanitasi menggunakan htmlspecialchars().
- Menggunakan SESSION.
- Menggunakan metode Post-Redirect-Get (PRG).

6. Pengujian

Melakukan pengujian menu navigasi, formulir, validasi, pengiriman data, dan memastikan fitur Kontak tetap berfungsi.

7. Teknologi

- HTML
- CSS
- JavaScript
- PHP
- Laragon
- Visual Studio Code
- Git dan GitHub
