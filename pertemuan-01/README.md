# pertemuan-01

Fungsi: dokumentasi capaian pembelajaran P1<br>
<br>
1. Konsep Dasar Pemrograman Web<br>
konsep dasar pemrograman web adalah proses pemnbuatan halaman web menggunakan bahasa pemrograman.<br>
2. Arsitektur Klien-Peladen<br>
struktur aplikasi yang membagi tugas atau beban kerja antara klien dan server.<br>
3. HTTP Request dan Response<br>
mekanisme komunikasi dua arah antara klien dan server web/halaman web.<br>
4. HTML, CSS, JavaScript, PHP, MySQL<br>
HTML adalah bahasa penandaan yang berfungsi menyusun struktur dasar, teks, gambar, dan tautan pada suatu halaman web.<br>
CSS adalah  Bahasa gaya tampilan yang mengatur warna, ukuran, tata letak, dan estetika visual halaman.<br>
Java Script adalah Bahasa pemrograman yang memberikan fungsi interaktif, animasi, dan validasi data di sisi pengguna.<br>
PHP adalah bahasa pemrograman skrip sisi server yang bersifat terbuka dan banyak digunakan untuk pengembangan web.<br>
MySQL adalah adalah sistem manajemen basis data relasional (RDBMS) sumber terbuka (open-source) yang digunakan untuk menyimpan, mengelola, dan memanipulasi data.<br>
5. Hubungan Antarteknologi<br>
saling ketergantungan dan keterkaitan, di mana perkembangan satu teknologi akan memicu, mendukung, atau melahirkan teknologi lainnya.
